---
name: reality-first
description: Evidence protocol for planning, implementation, debugging, testing and delivery.
---
Inspect the actual repository, runtime and target environment. Establish branch, exact HEAD, dirty state, project map, architecture, schemas, migrations, CI and baseline. Classify material statements as VERIFIED, CORROBORATED, ESTIMATE, ASSUMPTION, UNKNOWN or DISPUTED. For each test record command, environment, exit code, exact HEAD and mock usage. For data record source, provenance, timestamps, units, licensing and read-after-write. For runtime record the complete user journey and real dependencies. Never fabricate progress, agent activity, data freshness, test results or deployment.
