# Бесплатный контур ИИ-разработки

## Цель

Использовать текущие GitHub-инструменты и бесплатные CI-проверки до тех пор, пока отдельный сервер или платный API не доказанно необходим. Не создавать Railway-сервисы и не запускать Vercel-проверки для изменений, которые не затрагивают приложение.

## Что уже есть в репозитории

- `.agents/skills/ub-mode/SKILL.md` — инженерные правила для совместимого ИИ-агента. Сам файл не устанавливает Crapper, Dryer, Mutator или UML Viewer.
- `.agents/skills/rea/SKILL.md` — инструкции подключения REA. Сам файл не запускает REA CLI и не регистрирует MCP.
- GitHub Actions — выполнение проверок по событию. Это CI, а не самостоятельная языковая модель: workflow не должен называться ИИ-агентом, пока он действительно не вызывает модель.

## Бесплатный путь без нового сервера

1. Работать с репозиторием через доступные GitHub-инструменты ChatGPT: читать исходники, готовить изменения на отдельной ветке и открывать PR.
2. Использовать существующий `ci.yml` и профильные workflows. Новые проверки запускать только по затронутым путям.
3. Этот workflow проверяет, что оба skill-файла существуют и содержат обязательные метаданные/разделы. Он не заявляет, что выполнял REA-анализ или инструменты ub-mode.
4. Railway оставить выключенным/без новых сервисов, пока не появится конкретная задача, которую невозможно решить через GitHub Actions и существующие интеграции.

## Если понадобится запуск REA

REA CLI/MCP требует отдельной установки и поддерживаемого клиента. Сначала прочитать официальный [порядок установки](https://rea.tools/get-started/) и сделать dry-run; до подтверждения плана не менять конфигурацию клиента. Не хранить токены и локальные конфигурации MCP в Git.

## Ограничения бесплатного решения

- У GitHub Actions есть лимиты в зависимости от видимости репозитория и тарифа аккаунта.
- Бесплатные квоты внешних моделей ограничены и могут меняться. Не добавлять ключи API и не запускать платные ресурсы без согласования.
- GitHub skill-файлы не подключают инструменты непосредственно к текущему чату ChatGPT.
- Не считать зелёную проверку навыков доказательством сборки, тестирования или работоспособности production-приложения.

## Проверка

Запустить локально или в CI:

```bash
node scripts/check-agent-skills.mjs
```
