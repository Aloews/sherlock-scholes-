## Задача 1 — доделать сбор: Soccer Wiki + ESPN, все команды со всеми игроками

`docs/soccerwiki_squads.py` уже ходит `/country.php` → `/country.php?countryId=XX`
→ `/squad.php?clubid=N` и берёт номер, имя, позицию, возраст и рейтинг ОДНИМ
запросом на клуб. 240 стран. Запуск: `APPLY=1 python docs/soccerwiki_squads.py`.

Чего не хватает:

1. **Страница игрока** `/player.php?pid=…` — рост, вес, нога, дата рождения,
   фото (`cdn.soccerwiki.org/images/player/…`, заглушка `missing_player.png` —
   отсеивать как заглушку TM). Ходить адресно: только за теми, у кого в колоде
   нет фото или характеристик.
2. **ESPN** вторым источником для тех же игроков. Клиент к ESPN уже написан:
   `football_scraper/scraper/espn.py`. ⚠️ ESPN отдаёт 403 из песочницы
   (Akamai, при любом User-Agent) и доступен только из GitHub Actions — сбор
   заводить шагом в `.github/workflows/daily-enrich.yml`, а не локальным
   прогоном.
3. **Ночной шаг** для Soccer Wiki в `daily-enrich.yml`, рядом с
   `roster_fill_cards.py`.

⚠️ Не заводи новых сборщиков там, где есть существующий: правь
`docs/soccerwiki_squads.py`. Сопоставление клубов делает SQL
(`resolve_club_key`), второй копии в питоне быть не должно.

## Правила, которые в этом проекте нарушать нельзя

* Проверяй боевым **anon**-ключом, а не служебным: у anon лимит запроса 3 с.
* `node scripts/check-prod.mjs` — единственная проверка, падающая по той же
  причине, по которой ломается приложение. У каждой новой проверки —
  отрицательный контроль.
* Девять локалей в одном коммите, `node scripts/check-i18n.mjs`.
* Пиши в базу пачками через PostgREST скриптами проекта, не по одной строке.
* Имена игроков — латиницей (`cardDisplayName`), интерфейс переводится.
* Модель не звать автоматически. Только кнопка «краткая суть» и раз в неделю.
